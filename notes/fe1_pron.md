## Pipeline (CPronouncer::Pronounce 0x1800479e0), `zf1_pron_sentence`

1. pass1 = 0x180047abc per word: type 0, no current pron, fragment action in {0,4,9} (mask 0x211), lang 0x409:
   container lookup (0x1800484b4 -> container vt+8 0x18001d850: +0x48 list (empty), then priority list +0x10 =
   [main LEX (0x1000), CEnMorph (0x4000)] - LEX is inserted at the head after the morph lexicon).
   i278 = map(source of the FIRST pron) (0x1800c349c: 0x1000->1, 0x4000->2, 0x8000->4, 0x10000->3, 1/2/0x20->5).
   All prons are added to the word's sorted list LAST to FIRST (so the first lexicon pron is current), fragment POS
   (if != 0xFFFF) overrides the word POS (word vt+0xe8), then the first pron (lexicon order) with an attribute set
   containing the word POS id becomes current (0x18004863c/0x18004874c/0x180048804).
2. pass2 = 0x180047eac per word still without pron: LTA OOV splitter (src 0x10) -> COMPOUNDPRON (src 9) ->
   CWordPronouncer mode 4 (0x1800c924c): should-spell test 0x18006043c (char-table V/C classes; all caps <=3 letters
   spell; 4 letters -> VC pattern table 0x180179aa0; otherwise spell unless it has both a V and a C letter), CART LTS
   (src 6) with the vowel check (CPhoneme vt+0x138), else spelling (0x18005bad4, char table name2 joined with '&',
   src 8).  Afterwards (i278 != 8) a pron equal to the letter spelling (0x18005856c, stress ignored, '-' == '&') is
   re-spelled (src 8).  The LTA LTS pre-processor (loc!180015410) is inactive (no [Romanization] INI keys).
3. fork C step: CPolyphony (0x1800c9e30) + CRF homographs (0x1800caca8, 0x180060158) - callback `p->poly`.
4. pass3 = 0x180017d1c per word: current pron not syllabified (0x18004cce4: every segment between '-'/'&' has one
   vowel, or no vowel with a sonorant and != 1 consonant) -> CSyllableSeg (0x1800cb2dc): drop markers, walk vowels
   right to left, extend the onset while [k..vowel) is a prefix of an onset record (78f6770d, 73 x {p1,p2,p3,0}),
   insert '-' before it (except for the first vowel).  Set with source 0x17 (list add, i278 unchanged).
5. pass4 = 0x1800563dc/0x180056450 (i368): 0 if loc!180010910 (text "A"/"I", NE category sp:datetime /
   sp:measurement / sp:commonTerms / sp:webUrl, or text contains '.'); else 1 if the pron equals the mode-5 spelling
   (letters and digits only); else if NE == sp:mixedAcronymWord respell (src 8) and 1.
6. finish: `pron` (+0x160) = names of the current pron.

Pron list semantics (CTTSPronunciationList, 0x18004d8d0): sorted by u16 compare, duplicates not added, the added /
found entry becomes current; SetPronunciation (word vt+0x88, 0x18014b210) is ignored when i278 == 20 (<pron>)
unless forced; an empty pron counts as "no pron" (0x180041a40).

## CART LTS (ac4aefcf; 0x18015f7b4 -> 0x18015fb70 -> 0x1800575d8)

Layout (loaders 0x180160854/0x180044ad8/0x180160738/0x1800448f8): letters table, outputs table (u32 secSize, n,
off[n] in wchars, poolBytes, pool), two bitset matrices (letters 44x1, output labels 297x9), question table
(u16[874]), per letter 1..n-1 a tree {u32 sec, nNodes, u32 node[], nLeafBytes, leaf[], nQ, u16 q[]}.
- node {u16 a, u16 b}: a&0x3fff == 0 -> leaf, b = output label (< 0x400) or distribution index (>= 0x400: entries
  at leaf + (b-0x400)*4, {u16 label<<6 | (count in entry 0), u16 freq}); else children at +a (true) / +a+1 (false),
  question expression at q[b].
- term t: qdef = D[t & 0x3ff]; op = t>>13, skip = (t>>10)&7.  qdef: bits 0-8 set row, 9-12 distance, bit 13
  forward, bit 14 = previous output labels instead of letters (and the label matrix).  Moving stops on a 0 (word
  boundary / label position -1).  Ops (false/true): 0: skip+1 / skip; 1: TRUE / skip; 2: FALSE / skip; 3: skip /
  TRUE; 4: skip / FALSE; 5: FALSE / TRUE; 6: TRUE / FALSE.
- beam of 32 states per letter (0x180160300), IEEE float scores (count*score/total), replace the worst only when
  strictly better; n-best (0x180160c08): normalise, MSVC qsort descending, renormalise top 10, keep >= 0.005, labels
  -> output strings joined by ' ' ('#x' dropped, '&' -> ' '), pick the first maximum.  Letters matched by
  CharLowerW, unknown characters skipped, at most 127 letters.
- 0x18015f884 converts names ('-' '1' '2' split off as own phones) via the phone set (case-insensitive).

## CEnMorph (loc!18005c8e0 -> 180008e50)

Suffix table loc!1800866b0 (33), rules loc!1800a7430 (32 x 0x90: suffix phones, POS from/to pairs, flags
1 = add 'e', 2 = i->y, 4 = doubled consonant, 0x10 = add 'l'), phone table loc!1800a8630.  Strip suffixes from the
end repeatedly, try stem variants per rule, stem lookups in the main lexicon keep a pron only if
phones(cons+vowels) < letters*1.2475 + extra ('x'->K S, 'u'->Y UW/UH/AX) (loc!180056b64).  Suffix phones
(loc!18005bbd4): plural/past allomorphs by the last phone class, POS mapped through the rule pairs (fallback
loc!18005c648).  Entry: one pron per distinct phone string, attribute set per POS = POS id chain (e.g. [NOM,noun]).

## OOV splitter (loc!18000a1d0) and compounds

- CEmailWordBreaker (sp:email/webUrl/filePath, loc!18003df7c/18003dd6c/18003e0cc/18003dcd0): longest known
  prefix k; repeatedly take the leftmost position whose remainder is known (else the last char alone); when that
  suffix starts inside the known prefix, the tail after the prefix is split the same way and the prefix kept;
  parts' first prons concatenated WITHOUT separator (unknown parts skipped), src 0x10.
- sp:mixedAcronymWord -> mode 5 spelling.
- CCompoundWordBreakerEnUS: letters only, 8..32 chars, not "eLearning", not itself known; split search
  loc!18003e310/18003f4d8/18003f384/18003f278 over (left,right) pairs with "known" = length <= 16 and in LEX+CEnMorph;
  merge parts < 4 chars, exactly 2 parts, each >= 2 chars and (>= 4 or all caps); each part's first pron, rejected
  when it has more than len+3 real phones; joined with '&' (src 0x10).  Else 1..4 A-Z letters -> spelled.
- COMPOUNDPRON (mode 8): the 19a6569a network (fork B runtime `zf1_net_parse`, mode 0) output text split on blanks;
  "tok/SPELL" or single letters spelled, "[a+b]/PRONUNCIATION" explicit phones, other tokens mode 7 (first lexicon
  pron, else 1..4 caps spelled (loc!180017f90), else LTS); joined with '-' (src 9); one token = not a compound.

Corpus 370/375. Remaining: "Ave." x2 and "Dr." x2 = COMPOUNDPRON parse gaps (fork B's chunk parser needed: the

## Domain lexicons

Words whose domain (s1b0) is not "none"/"general" are first looked up in that domain's lexicon (enUS.<Domain>.dat,
source 0x10000 -> i278 3; container vt+0 0x1800c1350), e.g. "can" (address) and "MO" -> Missouri inside compounds;
pass2's compound / OOV-splitter lookups use the word's domain too (`p->curdom`).  `zf1_pron_load_domains(dir)`.

## Known gaps

- COMPOUNDPRON depends on fork B's network parser; words it cannot parse (apostrophes, '_' '$' '.' inside words,
  accented letters, "R2-D2") fall back to LTS.
- domain "general"/"name" pronouncers (enUS.Name.dat RNN LTS) not ported.
- Case mapping outside Latin/Greek/Cyrillic uses zf_tolower (documented limitation of zf1_util.c).
- zf1_cart_predict uses static beam buffers (not thread safe).
