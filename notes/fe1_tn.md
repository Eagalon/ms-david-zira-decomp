# fe1_tn: named entities + text normalization (fork B)

Scope: the TransducerNetwork runtime, CNEDetector::FindNext, CTextNormalizer::Normalize, the fragment NE loop,
SAPI say-as categories, word domains (step 4) and Analyze step 7b (entity token -> normalized words).
Engine: MSTTSEngine_OneCore.dll 10.3.21207.0. Everything below was verified by running the engine through
`harness\zftap1_tn.exe` (direct calls of Normalize / FindNext / network best path on the live objects).

## Files
- `src\zf1_fst.{h,c}` generic TransducerNetwork runtime (loader, lattice tokenizers, agenda chart parser, result
  tree, flatten, permutation, 1-best with agreement variables, leaf text). Also used by fork A (COMPOUNDPRON).
- `src\zf1_walpha.h` UCRT `iswalpha` ranges (generated by `build\tn\gentab.c` on this machine; `iswspace` table
  is inline in zf1_fst.c).
- `src\zf1_fstpm.{h,c}` NE FST (CFstMatcher) loader + pmatch matcher; `src\zf1_wcase.h` UCRT iswupper/iswlower
  ranges (`build	n\gencase.c`).
- `src\zf1_tn.{h,c}` NE / TN API; `src\zf1_modules.c` hooks `hk_text_tokens`, `hk_tn_expand` (wired).
- `src\zf1_t_tn.c` test driver (same query format as the harness), `src\zf1_t_net.c` older net driver.
- `harness\zftap1_tn.c` oracle. Queries (one per line, TAB separated):
  `N cat text` Normalize, `E text` FindNext loop, `F text` same with the NE FST disabled (ne+0x28 = NULL),
  `C cat text` FindNext with a category, `P cat text` best-path tree (mode 2, tokenizer 0),
  `R text` best-path tree (mode 1, tokenizer 3), `M text` NE FST matcher matches (offset, length, tag),
  `S text` Speak with NE/TN logging.
- `tests\fe1\tn\`: `n1/nd/ne1/ne2/ne2f/qe` query sets, `*.out` engine, `*.c.out` port, `cmpn.py A B [n]`,
  `cmpx.py` (TN words vs david.dump), `mkn_from_dump.py` (N queries from the dump's TN hook lines).
  Build: PowerShell `build\tn\mk.ps1 zf1_t_tn.exe zf1_t_tn.c zf1_tn.c zf1_fst.c zf1_lex.c zf1_dat.c zf1_util.c`.

## NE FST (zf1_fstpm.c, resource bfc4309d/d2343132)
BingNlPlatform::Fst binary (Xerox-style), one compiled pmatch network; its DEFINITION property is the source
`[ commonTerms EndTag(sp:commonTerms%COST=20%POS=50%NOFST=0) | ... ]`. Loader details in the zf1_fstpm.c header
(scrambled strings: license 1 shifts every value by the network offset & 0x7f; arcs in DFS order; only final
state = target of the EndTag arcs). Matcher semantics (verified with the M mode, not transliterated): leftmost
start, longest end reached through a tag arc, all tags at that end; no cut between two PMATCH_ALPHA chars or two
chars that are neither alpha nor PMATCH_DELIM; resume after the match.
FindNext (FUN_180061910) with no category: text must be ASCII (else network); FST matches at the first offset ->
lowest COST (first strict minimum, FUN_180061f08); none -> "no entity" (the network is NOT asked); NOFST=1
(currency) -> network from the start; entity not on lattice token boundaries (tokenizer 3) -> re-run the FST
from the next token start after its offset. A non-zero POS of the chosen tag is stored even when that match is
then rejected (engine quirk, ";[" emoticon case).

## COMPOUNDPRON (zf1_pron_compound in zf1_pron_oov.c)
Per-position loop of FUN_1800cc510 (network parse at pos, mode 0; else lattice token; whole word at 0 = not a
compound). Single letters = UCRT iswupper||iswlower (FUN_18005898c; 'º' is lower -> spelled, empty name2).
All pieces are pronounced into one per-word 0x180 buffer zeroed once; the LTS vowel check (0x1800c924c ->
CPhoneme vt+0x138) scans the whole capacity, so stale phones of earlier longer pieces count
(zf1_pron_lts_word2 vscan).

## Network format (blob, all LE)
`GUID 8c339078-fb86-40eb-84de-7fb7add37406 | u32 v1,v2 | u16 nRules, u16 | u32 nB,nC,nD,nE,nF,nG,nH | u16 d0,d2 |
A[nRules] 64 B | B[nB] 12 B | C[nC] 16 B | D[nD] 4 B | E[nE] 28 B | F[nF] 8 B | G[nG] 4 B | H[nH] 12 B |
3 pools: {u32 present, u32 size, bytes}: pool1 UTF-16 strings (labels, categories, first-char sets),
pool2 UTF-16 rule names, pool3 bytes (lists) | u32 0 (regex part, absent in en-US)`.
- Rule A (u32[16]): 0 name (pool2), 1 first state (B), 2 nstates (low u16) / mask (high u16), 3 first arc (C),
  4 misc, 5 script (pool1; 0 everywhere in en-US -> no JScript), 6 category name (pool1), 7 permutation list
  (pool3: u32 n, u32 perm[n]), 8 category flag, 9 -, 10 attributes (G index, -1 none), 11 agreement-variable
  list (pool3: u16 n, u32 F index[n]), 12 category type (0 any, 1, 2 = normalize only), 13 first-char set (pool1),
  14/15 "may start with anything" flags.
- State B: u32 -, u32 arc list offset (pool3: u16 total, u16, {u16 arc index, u16}[total]; the first u16 at B+8
  of them are rule-call arcs, the rest terminal arcs), u16 nRuleCallArcs.
- Arc C: u16 index-in-rule (= terminal id stored in edges), u16 next state (0xFFFF = rule complete), u32 kind
  (0 call, 1 terminal, 2 lexicon terminal), rule call: u16 symbol (+8), u16 symbol (lattice mode 1, +10),
  u16 cost (+12, always 0); terminal: u32 input label list (D), u32 output label list (D).
- D: u32 offset of a label list (pool3: u16 n, u16, u32 E index[n]).
- Label E (u32[7]): type (0 text, 1 copy input, 3/4/5 glue left/right/both), kind (1 literal, 2 lexicon word),
  string offset, length (u16), case-insensitive, cost (u16, 0xFFFF = no output), attributes (G, -1 none).
- G: offset of an H index list (pool3: u16 n, u16, u32 H[n]); H: u16 id, u16 value, u32 kind (0 value, 1 route
  agreement variable to child #value), u32 polarity. Attribute id 0 = "POS" (lexicon attr-def), values = POS ids.
- F: u32 attribute id, u32 offset of a child-index list (pool3: u16 n, u16, u32[n]).

## Runtime (FUN_18000f2d4 / FUN_18000fc40 / FUN_180011ad0)
Uniform-cost agenda chart parser. Edge = {flags(2 bits), rule, state, start, end, u16 cost, child1, child2,
next-alternative}; ids start at d0 (lower ids in child2 = terminal arc index), at most 65535-d0 edges.
Processed edges are keyed by (flags, rule, state, start, end): a re-derivation of a processed key only becomes an
alternative (chained after the primary); an agenda key match with lower cost replaces/moves the agenda node
(inserted before the first node with cost >= new), new edges are inserted before the first node with a strictly
greater cost (FIFO). Complete edge: combine with active edges ending at its start; category-filtered rules may
not attach to the top rule (quirk: the filter flag stays open after the first non-top active edge). Active edge:
combine with complete edges starting at its end, predict the called rule when none matched (first-char filter),
then terminal arcs (all matching input labels; cost = min output label cost). Best = longest, then cheapest,
complete top-rule edge from the start with an end the lattice tokenizer accepts. Error 0x80041003 (edges full /
u16 cost overflow) keeps the best so far.
Lattice tokenizers: mode 0 (Normalize, COMPOUNDPRON): start/end = not between two iswalpha chars; mode 3
(NE): start after whitespace, "(<[{", or a quote preceded by whitespace; end before whitespace/")>]}" or before
!"',.:;? followed by whitespace (not "..."). Kind-2 labels look the word up in the MAIN lexicon (quirk: the final
lookup length includes the leading whitespace) and test lexicon attribute pairs (parent attr, attr) against H.
Result: binary tree per rule chain (e440/e708), ambiguity nodes = alternatives (children 1.. sorted with the MS CRT
qsort by cost); the MultiResult 1-best (A*, ties -> later alternative) = cheapest, ties -> later alternative;
agreement variables (rule +0x2c lists, kind-1 routing, binding at the first node with a kind-0 value) must
intersect, else the next path (only currency "dollar"/"dollars" before a noun uses them); no consistent path ->
Normalize keeps the original text, FindNext rejects the entity. Flatten (only below rules with a permutation or
+0x2c list), permutation new[i] = old[perm[i]] (currency symbol moved after the amount, some dates). Output text =
leaf texts joined with ' ' (glue types), "[break=Nms]" markers become i214 pauses.

## NE / TN call order for the integration (as wired in zf1_modules.c)
1. Fragment text piece (FUN_1800c4f10): category = "ml:" + <context id> (+ "_" format) if the network supports it
   (zf1_tn_sayas_category), then `zf1_tn_segment(text, sayas)` (FUN_1800c6888 FindNext loop). Plain spans ->
   CWhiteSpaceBreaker (flag 1); entities -> one token {entity=1, cat, pos = FindNext POS attribute}. Entity tokens
   with category "sp:compoundWord" get no ne_type (FUN_1800c4ab4: "U.S." stays one plain word).
   Non-entity tokens containing a digit (iswdigit, U+2074..2089, 00B2/00B3/00B9/2070) become "sp:default"
   entities (FUN_180071b70 / FUN_18004d0d4, coordinator).
2. Step 4 (FUN_18002bf08) for every word: `zf1_tn_domain` (s1b0 from say-as / sp: type) - done in hk_tn_expand.
3. Step 7a acronyms (fork A, may rewrite entity text, e.g. "St." -> "street"), then 7b `zf1_tn_expand`:
   Normalize(text, ne_type) and replace the token (FUN_18004b06c fields: type 0, text/ci, i27c 1, ne_type, s1b0,
   src_off/len of the token, bi 2 + i248 1 except on the last output word, "[break=N]" -> previous word i214 += N,
   i248 = 0); single-word result keeps the token POS (zf1_pos_set), then POS re-tag of the new words.
   The "-SIL-" words for i214 are inserted later by sentence vt+0xa0 (FUN_18001a644, coordinator).
